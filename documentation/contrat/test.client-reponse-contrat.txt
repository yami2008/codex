## Pour rejouer les tests

1. Préparer le contrat de test (base egsa_operation, sqlcmd avec -I) : statut VALIDE_JURIDIQUE, date_visa renseignée, aucune ligne dans contrats_envois.
   Exemple de remise à l'état de départ :
   UPDATE contrats SET statut = 'VALIDE_JURIDIQUE', date_signature_client = NULL WHERE id = '<id du contrat>';
   DELETE FROM contrats_envois WHERE contrat_id = '<id du contrat>';
2. Se connecter avec le compte test (rôle commercial). Le rôle JURIDIQUE a été retiré de ce compte le 2026-10-10 : le visa juridique ne peut pas être joué avec lui, il faut passer le contrat à VALIDE_JURIDIQUE directement en base.
   Pour les requêtes UPDATE sur la table contrats, lancer sqlcmd avec l'option -I (sans elle, SQL Server refuse avec l'erreur 1934 sur QUOTED_IDENTIFIER).
3. Pour rejouer 3.x et 4.x, remettre le contrat à ENVOYE_AU_CLIENT et supprimer la réponse de contrats_envois (reponse_client et date_retour_client à NULL).
4. Contrôles en base : tables contrats, contrats_envois et contrats_historique_statuts de egsa_operation, filtrées sur contrat_id.
5. Les appels HTTP (POST envoyer-client, marquer-signe-client, refuser-client) se contrôlent dans l'onglet réseau du navigateur.
